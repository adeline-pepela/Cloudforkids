# Photo slots

Drop a JPG with the exact file name into this folder and it replaces the coloured placeholder on that
spot. No code change or restart needed (hard refresh the page). Use landscape 4:3 images, about
1600x1200 px (the two wide banners, `impact` and `partners`, are 16:7, about 1600x700 px).
