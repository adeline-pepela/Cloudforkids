# Partner logos

Save each partner's official logo here, named after the partner (lower case, spaces as dashes), as .svg, .png, .jpg or .webp:

aws-konza-technopolis, aws-usergroup-kenya, ajira-digital-centres, amazon-web-services, konza-jitume-hubs,
mastercard-foundation-emobilis ...

It then shows on the home and Partners pages. You can also upload a logo on the partner in Admin > Partners (which wins if both exist).
