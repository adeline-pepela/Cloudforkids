Topic 1: Cloud Databases - Storing Data at Scale

Cloud databases are designed to store massive amounts of data reliably, securely, and accessibly. Unlike traditional databases on single computers, cloud databases spread data across multiple servers for reliability and performance. There are two main types: relational databases (structured data in tables) and NoSQL databases (flexible, document-based data).

Relational databases (SQL): Data is organized in tables with rows and columns. They are used for structured data like customer records, transactions, and inventory. Examples: Google Cloud SQL, Amazon RDS, Microsoft SQL Server in the cloud. They offer strong consistency - the data is always correct and up to date. Good for: banks (transactions), e-commerce (orders), schools (grades).

NoSQL databases (such as MongoDB and Firebase): Flexible data storage - documents instead of tables. They are used for less structured data like social media posts, sensor data, and user profiles. Examples: Google Firebase, AWS DynamoDB, MongoDB Atlas. They offer fast reads and writes - they are optimized for speed. Good for: real-time applications, large-scale web apps, mobile apps.

Key Takeaways
  • Cloud databases spread data across many servers, so they are reliable and fast
  • Relational (SQL) databases store structured data in tables of rows and columns, with strong consistency
  • Use relational databases for banks, e-commerce orders and school grades
  • NoSQL databases store flexible documents and are optimized for speed
  • Use NoSQL databases for real-time apps, large web apps and mobile apps
  • Replication keeps copies of the data on several servers, so one failure does not lose data

Topic 2: APIs & Backend Services - Connecting Frontend to Data

An API (Application Programming Interface) is the bridge between the frontend (user interface) and the backend (data). APIs expose data and functions that applications use. When you open WhatsApp and see your messages, the WhatsApp frontend calls a WhatsApp backend API to fetch your messages from a cloud database.

REST APIs are the most common kind. REST (Representational State Transfer) defines standard ways to reach data over HTTP. For example: GET /students returns a list of all students. POST /grades adds a new grade. PUT /students/123 updates student 123. DELETE /grades/456 removes grade 456.

The Four REST Actions
  • GET /students - read: returns the list of all students
  • POST /grades - create: adds a new grade
  • PUT /students/123 - update: changes student 123
  • DELETE /grades/456 - delete: removes grade 456
  • The server answers with JSON data, which the frontend shows on screen
Picture It: How an App Gets Your Messages

The frontend asks the API for data, the backend fetches it from the database, and the answer comes back as JSON.

Frontend → API request (GET /messages) → Backend → Database → JSON response → shown on screen

Quiz Time

Which database type is best for storing customer transaction records?

Relational database (SQL) - structured, reliable, consistent - Banks and financial services use relational databases because transactions must be consistent, reliable, and accurately tracked. SQL databases guarantee these properties.

What is a major advantage of cloud databases over local databases?

Data is replicated across servers so it survives hardware failures - Cloud databases copy data across multiple servers. If one server fails, the others have copies. A database on a single computer risks losing everything if that hardware fails.

What is an API in cloud applications?

Interface that allows frontend to request data from backend/database - APIs are the bridge between the user interface and backend services. They define how applications communicate and share data.

In a REST API, what does GET /messages do?

Retrieves/fetches list of messages from server - A GET request retrieves data. POST creates, PUT updates, DELETE removes. These are the standard REST operations that backends offer through APIs.

Compare relational and NoSQL databases. When would each be used?

Relational: structured data, strong consistency (banks, e-commerce); NoSQL: flexible data, high speed (real-time apps) - Each type has strengths. Choose relational when data must always be consistent, like money and orders, and NoSQL when you need flexibility and speed, like live feeds and mobile apps.

How do APIs enable modern web applications?

They are the bridge that lets the frontend and backend communicate and share data from databases - APIs connect the parts of an application: the frontend asks, the backend answers with data from the database. This keeps each part separate and simple.

You are designing a short-video social media app. Which set of components does it need?

Frontend for the user interface, backend for logic, database for videos and profiles, CDN for fast video delivery, and a cache for performance - A big app needs every layer: the frontend people use, the backend logic, a database, a CDN to deliver videos quickly around the world, and caching to keep things fast.

In M-Pesa (Kenya), when you send money, what happens in the cloud?

Backend database records transaction, ledgers updated, confirmation sent to phone - No coins travel through the internet: the backend records the transaction in its database, updates both accounts, and sends a confirmation message to each phone.
