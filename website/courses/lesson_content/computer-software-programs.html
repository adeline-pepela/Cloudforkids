Topic 1: What Is Software? Programs That Control Hardware

Software is a collection of instructions that tells computer hardware what to do. You cannot see or touch software, but you use it every time you use a computer. Every app on your phone - WhatsApp, YouTube, Instagram, M-Pesa - is software. Every program on a computer - games, word processors, web browsers - is software.

Software is written by programmers using programming languages like Python, Java, C++ and JavaScript. The programmer writes code (instructions) that the CPU understands and executes. When you click a button in WhatsApp, you are triggering software code that tells the CPU to send a message. The CPU then follows those instructions to send the message through the internet to your friend.

Without software, hardware is just useless metal and circuits. A powerful computer with no software installed cannot do anything. An old computer with useful software installed is more valuable than a powerful computer with no software. This shows how important software is.

In Kenya, software is crucial: banks use software to run M-Pesa, schools use software for student records, hospitals use software for patient data, and businesses use software to operate. Understanding software helps you appreciate the work of programmers and opens doors to career opportunities in software development.

Key Takeaways
  • Software is a set of instructions - you cannot touch it, but you use it every time you use a computer
  • Every app (WhatsApp, YouTube, M-Pesa) and every program (games, browsers, word processors) is software
  • Programmers write software in languages like Python, Java, C++ and JavaScript
  • The CPU follows the software's instructions - for example, to send your WhatsApp message
  • Without software, even a powerful computer cannot do anything

Topic 2: Operating Systems - The Main Software

An operating system (OS) is the main software that controls computer hardware and allows other programs to run. It is the first program that loads when you turn on a computer. Common operating systems include Windows (for PCs), macOS (for Apple Macs), Linux (for servers and some PCs), Android (for phones and tablets), and iOS (for iPhones and iPads).

The operating system has many jobs: manage files and folders, control hardware (CPU, RAM, storage), run applications, manage memory, control security and permissions, handle input and output devices, manage power usage, and provide a user interface (the screen you see).

The operating system is like a manager in an office - it coordinates all the workers (programs and hardware) to make sure everything runs smoothly and no one interferes with each other. If you try to open too many programs at once, the computer slows down because the OS is managing too many things at the same time. The OS decides which program gets CPU time, which gets memory, which can access files, and what each program can do.

In Kenya, most school computers use Windows. Most school tablets and phones use Android or iOS. Many internet servers use Linux. Understanding the OS helps you understand why different devices work differently and why you cannot just move a Windows program to a Mac without modification.

Key Takeaways
  • The operating system (OS) is the first program that loads when you turn on a computer
  • Common operating systems: Windows (PCs), macOS (Apple Macs), Linux (servers and some PCs), Android (phones and tablets), iOS (iPhones and iPads)
  • The OS manages files, hardware, memory, security, input and output, and power, and gives you the screen you see
  • The OS is like an office manager - it decides which program gets the CPU, memory and files
  • Opening too many programs at once slows the computer down
  • Programs are made for one OS, so a Windows program cannot simply run on a Mac

Game Time: Operating System Challenge

Game Type: Role-playing simulation game

What it is

Students act as an operating system managing hardware and programs.

How to play

  1. One student is the "Operating System (OS Manager)"
  2. Other students are "Programs" (Chrome, Word, Game, Email) and "Hardware" (CPU, RAM, Storage, Monitor)
  3. Each program wants to use the CPU and RAM at the same time
  4. The OS must decide: Which program gets the CPU first? How much RAM for each? What displays on the monitor?
  5. If two programs need the same resource, the OS decides priority and order
  6. If RAM fills up, the OS decides what to keep in and remove from memory
  7. Simulate lag: if the OS tries to run too many programs, everything slows down
  8. Rotate roles so each student is the OS, a program, and hardware
  9. Discuss: What happens in real computers when you open too many programs?
Topic 3: Types of Software - Different Programs for Different Jobs

There are different types of software, each serving different purposes. System Software controls the hardware and keeps the computer running. Examples: Operating System, Device Drivers, BIOS.

Application Software does specific tasks for users. Examples: Word processors (Microsoft Word), Browsers (Chrome), Messaging apps (WhatsApp), Social media (Facebook, TikTok), Games, Calculators, Email programs.

Utility Software maintains and optimizes the computer. Examples: Antivirus software (protects from viruses), File compression (makes files smaller), Disk cleaners (free up storage), Backup software (copies important files), Screen recorders (record screen activity).

Web Applications run in web browsers, not installed on your computer. Examples: Gmail (email in browser), Google Docs (documents in browser), Facebook (social media in browser), YouTube (video in browser). Mobile Applications run on smartphones and tablets. Examples: WhatsApp, Instagram, TikTok, M-Pesa, games.

In Kenya, people use all types of software: system software runs on bank servers for M-Pesa, application software on phones for WhatsApp, web applications for email and shopping, and mobile apps for transactions and communication. Understanding software types helps you choose the right tool for each task.

Types of Software
  • System Software: controls the hardware and keeps the computer running (Operating System, Device Drivers, BIOS)
  • Application Software: does specific tasks for users (Microsoft Word, Chrome, WhatsApp, games, calculators, email)
  • Utility Software: maintains and optimizes the computer (antivirus, file compression, disk cleaners, backup, screen recorders)
  • Web Applications: run in a web browser instead of being installed (Gmail, Google Docs, Facebook, YouTube)
  • Mobile Applications: run on smartphones and tablets (WhatsApp, Instagram, TikTok, M-Pesa, games)
Quiz Time

What is software?

Instructions and programs that tell hardware what to do - Software is the intangible (not physical) set of instructions. While hardware is physical, software is the code and programs that run on that hardware.

Which of these is software?

WhatsApp, YouTube, games, Microsoft Word - Apps and programs like WhatsApp, YouTube, games, and word processors are all software. They are programs running on the hardware to do specific tasks.

What is the job of an operating system?

Control hardware, run applications, manage files, and coordinate all computer resources - The OS is the main manager. It controls hardware, allows programs to run, manages memory and files, handles user input, and coordinates all computer resources.

What happens first when you turn on a computer?

The operating system loads first - When you press the power button, the CPU first loads the operating system from storage into RAM. Once the OS is loaded, you see the desktop, and then you can open other programs.

Which type of software is WhatsApp?

Application software (specifically mobile application) - WhatsApp is an application designed to do a specific task: send messages. It is installed on phones, making it a mobile application.

What type of software protects your computer from viruses?

Utility software like antivirus programs - Antivirus software is utility software. It runs continuously, monitoring for dangerous software (viruses, malware) and protecting your files and privacy.

Why is software necessary for computers?

Software gives instructions that tell hardware what to do - Software is essential. Hardware cannot function without software giving it instructions. Without software, even the most powerful hardware is useless metal and circuits.

What is the most important role of the operating system?

To manage hardware resources and allow other programs to run - The OS is the manager. It controls CPU, RAM, and storage, decides which programs get resources, and allows all programs to run without interfering with each other.

If a computer has excellent hardware but no software installed, what can it do?

Almost nothing - hardware needs software instructions - Hardware is like an empty brain. Software provides the instructions. Without software, powerful hardware cannot function.

Why do different programs require different operating systems?

Programs are written specifically for the OS they need to run on. Different OS have different instructions. - Programmers write code specifically for the OS where the program will run. Windows programs use Windows instructions, Mac programs use macOS instructions. Different operating systems work in different ways.

In Kenya, which software application stores your money in the cloud?

M-Pesa application - The M-Pesa app is software that connects to Safaricom's servers where your money is recorded in the cloud. This is an example of how software and cloud storage work together in Kenya.
