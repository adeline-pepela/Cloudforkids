Topic 1: Files and Folders - Organizing Digital Information

A file is a collection of data stored on a computer. It could be a document (Word file), a photo (image file), a video (video file), a song (audio file), or a program (executable file). Each file has a name and a file extension that tells the computer what type of file it is. For example: "essay.docx" (Word document), "photo.jpg" (image), "video.mp4" (video), "song.mp3" (music), "game.exe" (program).

A folder is a container that holds files and other folders. Folders help organize files logically, just like filing cabinets organize documents. You can have folders inside folders, creating a hierarchy. For example: the "My Documents" folder contains a "School" folder, which contains a "Math" folder, which contains the "homework.docx" file.

The main folder on a computer is called the "root", or the "C: drive" on Windows. From there, you navigate through folders to find files. Most computers have standard folders: Documents (for text files), Pictures (for images), Downloads (for internet downloads), Music (for audio files), Videos (for video files), and Desktop (for quick access items).

Organizing your files is important because it saves time finding things, prevents losing important files, makes sharing files easier, and shows professionalism. In Kenya, school students use computers with organized file systems. Teachers expect assignments in organized folders by name, date, and subject. Understanding file organization is a critical computer skill.

Key Takeaways
  • A file is a collection of data: a document, photo, video, song or program
  • The file extension (like .docx, .jpg or .mp4) tells the computer what type of file it is
  • A folder holds files and other folders - folders inside folders make a hierarchy
  • Example path: My Documents → School → Math → homework.docx
  • The main folder is the "root" (the C: drive on Windows)
  • Standard folders: Documents, Pictures, Downloads, Music, Videos and Desktop
  • Good organization saves time, prevents lost files and makes sharing easier

Topic 2: File Types - Different Data, Different Formats

Different files store different types of information. Understanding file types helps you work with information effectively.

Document files (.doc, .docx, .txt, .pdf) store text and formatting. They are created by word processors (Microsoft Word, Google Docs). Image files (.jpg, .png, .gif) store pictures, created by cameras, phones, or graphics programs. Video files (.mp4, .avi, .mov) store moving pictures with audio and have large file sizes; they are created by cameras and phones, or downloaded. Audio files (.mp3, .wav, .flac) store sound and music, created by microphones, phones, or music apps.

Spreadsheet files (.xls, .xlsx, .csv) store data in tables and cells, allowing calculations. They are created by Excel or Google Sheets. Executable files (.exe, .app, .apk) are programs that run - they tell the computer to do something. Be careful: dangerous executable files can hide viruses. Archive files (.zip, .rar) compress multiple files into one smaller file for storage or transfer. Code files (.py, .java, .js, .cpp) store programming code written by developers. Database files (.db, .sql) store organized data that can be searched and sorted.

In Kenya, students work with document files (assignments), image files (photos), video files (YouTube videos), and spreadsheet files (grades). M-Pesa and banking apps use databases to store transaction data. Understanding file types helps you know what program to use for each task.

Common File Types
  • .docx - Word document (text with formatting)
  • .pdf - Portable Document Format (universal document format)
  • .txt - Plain text file (text only, no formatting)
  • .jpg / .jpeg - Image file (photographs)
  • .png - Image file (graphics with transparency)
  • .gif - Image file (animations)
  • .mp4 - Video file (video with audio)
  • .avi - Video file (older format)
  • .mp3 - Audio file (music and sound)
  • .wav - Audio file (high quality sound)
  • .xlsx - Excel spreadsheet (data in tables)
  • .csv - Comma-separated values (data export format)
  • .zip - Compressed archive (multiple files compressed)
  • .rar - Compressed archive (alternative to zip)
  • .exe - Executable program (Windows programs)
  • .app - Executable program (Mac programs)
  • .apk - Mobile app (Android phone apps)
  • .py - Python code file (programming)
  • .js - JavaScript code file (web programming)
  • .html - Web page file (internet pages)

Quiz Time

What is a file?

A collection of data stored on computer (document, photo, video, etc.) - A file is a unit of stored information. Different files hold different types of data: documents hold text, photos hold image data, videos hold moving pictures, and so on.

What does the file extension ".docx" tell you?

It is a Microsoft Word document file - File extensions show the file type. ".docx" means Microsoft Word document. ".jpg" means image. ".mp4" means video. The computer uses the extension to know which program should open the file.

Which file type should you use to store a photograph?

.jpg or .png (image file) - Image files like .jpg and .png are designed to store photographs and pictures. They preserve quality and are much smaller than videos.

What is the advantage of .zip files?

They compress multiple files into one smaller file for easier storage and sending - .zip files (archives) compress files to make them smaller. This saves storage space and makes sending files faster over the internet. You can put multiple files into one .zip file.

How should you organize your files on a computer?

In folders by category (Documents, Pictures, School, Work) with logical subfolders - Logical organization (by subject, date, type) saves time finding files, prevents losing important documents, and shows professionalism. Good organization is a valuable computer skill.

Why is file organization important?

Saves time finding files, prevents data loss, shows professionalism - Good file organization is a critical skill: it saves time, prevents losing important documents, makes sharing easier, and shows you are responsible with digital data.

What is the file extension for a compressed archive that combines multiple files?

.zip or .rar - .zip and .rar files are archive formats that compress multiple files into one smaller file. This saves storage space and makes sharing files over the internet faster.

What happens when you delete a file from the Recycle Bin (Trash)?

The file is permanently deleted from storage - Emptying the Recycle Bin deletes the file for good: you can no longer open it or restore it from the bin. Behind the scenes its space is marked as free, so until new data is saved over it, special software can sometimes rescue it - after that, recovery is impossible.
