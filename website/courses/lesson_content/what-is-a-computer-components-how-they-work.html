Topic 1: What Is A Computer? Understanding the Machine

A computer is a machine that takes information as input, processes it, and gives you output. It follows instructions (programs) to do useful work. Computers are everywhere: in homes (desktops, laptops), in pockets (smartphones, tablets), in schools (computer labs), in offices (servers), and in cars (embedded computers).

In Kenya, computers are essential: banks use them for M-Pesa, schools use them for learning, hospitals use them for patient records, and businesses use them for operations.

There are different types of computers: Personal Computers (PCs) for individuals, servers for storing data, tablets for touch-based computing, smartphones for mobile computing, and embedded computers in devices. All computers share the same basic components and principles: they have a processor (brain), memory (short-term storage), storage (long-term storage), input devices (keyboard, mouse, touchscreen), and output devices (screen, speaker). Understanding computers helps you use them better and opens doors to tech careers.

Key Concepts
  • Computer: Machine that processes information following instructions
  • Hardware: Physical parts of a computer you can touch
  • Software: Programs and applications that run on computers
  • System: Collection of parts working together
  • Input: Information going INTO the computer
  • Process: Computer working on the information
  • Output: Results coming OUT from the computer
  • Kenya Computing: Banks (M-Pesa), Schools, Hospitals, Businesses all use computers

Game Time: Computer Components Detective

Game Type: Matching game

What it is

Students match computer components to their functions. Each component card has a matching card that says what it does. Students find the matching pairs.

How to play

  1. Lay out 8 component cards face down (CPU, RAM, Storage, Monitor, Keyboard, Motherboard, Power Supply, Speaker)
  2. Lay out 8 function cards face down (Displays output, Provides input, Controls everything, Stores programs, Fast memory, Powers computer, Connects components, Makes sound)
  3. Students flip two cards and try to match a component with its function
  4. If the match is correct, keep the pair and score 1 point
  5. If there is no match, flip the cards back over
  6. Continue until all pairs are found
  7. The student with the most pairs wins

Make it easier or harder

  • Advanced: Increase to 12 components
  • Beginner: Decrease to 6 components for younger students
Topic 2: Computer Hardware - The Physical Parts

Computer hardware refers to the physical parts of a computer that you can see and touch. The main components are: CPU (Central Processing Unit - the brain), RAM (Random Access Memory - short-term memory), Storage (permanent storage for programs and files), Motherboard (connects all parts), Power Supply (provides electricity), Input devices (keyboard, mouse, touchscreen), and Output devices (monitor, speaker, printer).

Each component has a specific job. The CPU is like the brain of the computer - it makes decisions and runs instructions. RAM is like a desk where the CPU works - it holds information temporarily while the computer is on. Storage is like a filing cabinet - it keeps programs and files saved even when the computer is turned off. The motherboard is like the nervous system - it connects all parts so they can communicate.

Input devices let you tell the computer what to do (keyboard for typing, mouse for clicking, touchscreen for touching). Output devices show you the results (monitor for pictures, speaker for sound, printer for paper).

In Kenya, computer labs in schools have many of these components. A typical school computer has a CPU, RAM, storage drive, monitor, keyboard, and mouse. Understanding hardware helps you troubleshoot problems and choose the right computer for tasks.

Main Components Explained
  • CPU (Central Processing Unit): The brain of the computer. Makes decisions and runs all instructions. Speed measured in GHz.
  • RAM (Random Access Memory): Fast temporary memory. Loses data when the computer turns off. More RAM = faster computer.
  • Storage (Hard Drive or SSD): Permanent storage. Keeps programs and files saved even when the computer is off. Measured in GB or TB.
  • Motherboard: Main circuit board. Connects CPU, RAM, storage, and all other parts. Allows communication between components.
  • Power Supply: Converts electricity from the wall outlet into power for computer components.
  • Monitor: Output device. Displays pictures and information for you to see.
  • Keyboard: Input device. Lets you type letters, numbers, and commands.
  • Mouse: Input device. Lets you point, click, and move around the screen.
  • Speaker: Output device. Produces sound - music, alerts, voices.
  • Printer: Output device. Prints digital information onto paper.

Game Time: Build Your Computer

Game Type: Assembly puzzle game

What it is

Students arrange computer components in the correct order to build a working computer system.

How to play

  1. Give each student or team a list of components that need to be installed in order
  2. Components include: Case, Power Supply, Motherboard, CPU, Cooling Fan, RAM, Storage and Connections
  3. Students write down the correct installation order (power supply first, then motherboard, and so on)
  4. After installing in the correct order, the computer "turns on" and works!
  5. If the order is wrong, tell them which component fails - they fix it and try again
  6. The fastest team to build a working computer wins
  7. Discuss why the order matters - some components must go in first for others to work

Practice Lab: Build Your Computer - put the parts into a computer case in the right order, then switch it on.

Topic 3: System Architecture - How Components Work Together

A computer is not just individual parts - it is a system where all parts work together. The motherboard is the central hub connecting everything. The power supply provides electricity to all components. The CPU reads instructions from RAM and storage, processes them, and sends results to output devices like monitors.

When you click a mouse (input), the keyboard and mouse controllers send signals to the CPU through the motherboard. The CPU processes your click and tells the monitor what to display (output). This happens thousands of times per second! All components communicate through the motherboard using electronic signals.

Think of it like a city: the motherboard is the roads, the CPU is the mayor making decisions, RAM is temporary workers holding tools, storage is the library with permanent records, input devices are how citizens communicate with the mayor, and output devices are how the mayor broadcasts decisions.

A computer only works when all these parts are connected and functioning. If one part fails, the whole system might not work. This is why computers need maintenance - keeping all parts clean, cool, and functional. In Kenya, when a school computer breaks, IT technicians check each component to find the problem. Understanding how components work together helps you understand why computers have certain limitations and capabilities.

Component Relationships
  • CPU controls: The CPU is the boss. It controls RAM, storage, and tells output devices what to display.
  • Motherboard connects: All components plug into or connect to the motherboard. It is the communication hub.
  • Power supply powers: Everything needs electricity. The power supply provides this to all components.
  • RAM helps CPU: The CPU works in RAM. More RAM means the CPU can do more at the same time.
  • Storage feeds CPU: Programs and data come from storage into RAM for the CPU to process.
  • Input tells CPU: Input devices (keyboard, mouse) send signals that tell the CPU what the user wants.
  • CPU tells Output: The CPU sends instructions to output devices (monitor, speaker) to show results.
  • Feedback loop: Output shows results, the user sees results, the user gives new input, and the cycle continues.

Every component connects and communicates through the motherboard.

INPUT (Keyboard, Mouse) → Motherboard ← CPU ↔ RAM | STORAGE → Motherboard ← Power Supply | Motherboard → OUTPUT (Monitor, Speaker)

Game Time: Computer Doctor: Fix the System

Game Type: Diagnosis and repair game

What it is

Students troubleshoot a broken computer by identifying which component failed and needs replacement.

How to play

  1. Present a computer problem: "Screen is dark but you hear beeping"
  2. Give students 5 possible causes: Monitor broken, Graphics card broken, CPU broken, Power broken, Motherboard broken
  3. Students ask yes/no questions to narrow down the problem
  4. Example: "If the power was broken, would the computer beep?" (no) "If the monitor was broken, could the computer still beep?" (yes)
  5. Through questions, students identify the broken component
  6. Challenge with increasing difficulty: more components, more vague symptoms
  7. The fastest student to identify the problem wins
Quiz Time

What is the main purpose of a computer?

To take input, process it, and produce output - Computers are designed to process information according to programs. They take input (data), process it using the CPU, and produce output for users.

Which of these is an example of a computer?

Desktops, laptops, tablets, smartphones - all are computers - Computers come in many sizes and types. Smartphones, tablets, laptops, and desktops are all computers with processors, memory, and storage.

What does the CPU do?

Makes decisions and runs all computer instructions (brain of computer) - The CPU is the processor - the brain of the computer. It executes all instructions from programs and controls other components.

What is RAM used for?

Fast temporary memory for programs running right now - RAM (Random Access Memory) is fast temporary memory. The CPU uses it to run programs. RAM is cleared when the computer turns off, so data is not permanently saved there.

Which components are input devices?

Keyboard and mouse - Input devices let you give information to the computer. Keyboard for typing, mouse for clicking, touchscreen for touching. These are how you communicate with the computer.

If storage is broken but RAM and CPU work, can the computer start?

No, computer needs storage to load the operating system - Storage contains the operating system and programs. The CPU and RAM cannot function without loading these from storage first. Broken storage means the computer cannot start.

What is the role of the motherboard?

Connects all components and allows them to communicate - The motherboard is the central circuit board. All components connect to it. It allows CPU, RAM, storage, and peripherals to communicate. Without it, components cannot work together.

Which component is most important for a computer to function?

CPU (the brain that processes everything) - The CPU is the processor - the brain of the computer. Without a CPU, no processing can happen. You might be able to see a monitor, but without a CPU there is nothing to display.

If you increase RAM from 4GB to 16GB, what improvement would you notice?

Computer runs faster and can run more programs simultaneously - RAM affects speed and multitasking ability. More RAM means the CPU can work with more programs at once without slowing down from swapping data between RAM and storage.

A computer is composed of which two main parts?

Hardware and software - Every computer has physical parts (hardware) and programs (software). Both are essential for the computer to function.

What is the relationship between RAM and storage?

RAM is fast temporary memory; storage is permanent. CPU works in RAM; data comes from storage. - RAM is like a desk (temporary work area), storage is like a filing cabinet (permanent archive). The CPU works in RAM with data pulled from storage.

If your computer is running slowly, what is a possible hardware cause?

Insufficient RAM causing CPU to wait for memory operations - Insufficient RAM forces the CPU to frequently swap data between RAM and slow storage, causing slowdowns. More RAM allows faster processing of multiple programs at the same time.
